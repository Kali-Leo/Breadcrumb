# 知识地图：墨水航海图（Leo 的设计，2026-07-29）

> 知识树的最终形态不是侧边栏列表，而是一整页**童话风简笔画墨水航海图**。
> 侧边栏只做导航与锚定；世界在地图页。

## Leo 的原始设计（完整保留）

- 独立页面，默认呈现一片地图：童话风游戏经典的简笔画墨水航海图/宝藏图画风
- **相关的知识聚成一处地点，不相关的知识是另一处地点，地点之间用空白（海）隔开，
  越不相关离得越远**
- **学得越多，地点越大**：小房子 → 村庄 → 大城
- 滚轮缩小 → 更大范围 → 再缩小 → 全局视图
- 滚轮在某地区上放大 → 展开该地区内部的知识结构（同样按相关性布局）；
  在空白处放大只有回弹效果
- 相关性判定：宏观用**词向量**统计分析；特别微观时用**知识图谱**
  （开源候选：Wikidata / ConceptNet / DBpedia，实现前验证）
- 视觉灵魂：大城市里有走来走去的居民（海盗猫猫、居民猫猫），小房子偶尔冒烟——
  与学习无关，但**是产品哲学的具象**：学习的奖赏是"我的世界热闹起来了"（减压第一）

## 设计合流（与 03-地图与罗盘 的统一）

Leo 的地图让 03 号文档的隐喻全部落地成同一个画面：

| 概念 | 在航海图上的形态 |
|------|-----------------|
| 用户知识树（地图） | 地图本身：地点、城市、地区 |
| 遗忘（天气） | **迷雾**：久未踩足的地区被雾慢慢笼罩；重访则雾散。永不用红色警告 |
| 对话方向（罗盘） | 本次对话 = 航线：从出发港划过海面的一道墨水航迹 |
| 职业对照 | 远方的目标群岛：模糊轮廓标在海平线上，"下一步"=最近的可达岛屿（KST 外缘） |
| 面包屑轨迹 | 航海日志：每天的航行记录 |

## 技术方案草案（实现前逐项验证）

1. **布局**：知识节点 embedding →二维投影（UMAP/力导向）→ 聚类成"地区"；
   地点大小 = 节点数。embedding 来源：本地小模型（离线原则，transformers.js/ONNX 类）
   或用户 API，均计价可关
2. **渲染**：Canvas/WebGL（候选 pixi.js）+ 手绘风（候选 rough.js）+
   语义缩放（LOD：全局 → 地区 → 地区内部结构）
3. **参考**：Azgaar's Fantasy Map Generator（开源墨水风地图生成）、经典 fog-of-war 实现
4. **微观层**：地区内部展开时用知识图谱关系补齐（Wikidata/ConceptNet 候选）
