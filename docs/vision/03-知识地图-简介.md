# 知识地图 · 简介

把用户学过的知识（知识树聚类）可视化为一个可缩放探索的古典海图世界，
帮助学习者纵览所学、发现联系、辅助回顾。

- 首轮实现（AI 生成贴图路线）已于 2026-07-30 整体废弃移除
- 重启版走**程序化矢量制图**路线（Voronoi + 种子噪声 + 代码线稿，零图片资产），
  规格见 `specs/008-procedural-knowledge-map/`，架构决策见 ADR-0004
- 层级映射：知识树深度 0/1/2/3+ → 岛屿/王国/村庄/知识点；
  滚轮缩放即语义缩放；遗忘表现为海图起雾（spec 007）
- 铁律：同一棵树永远生成同一张图；新增知识不移动既有岛屿
