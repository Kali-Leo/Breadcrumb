# 记忆宫殿（原知识地图）· 简介

把用户学过的知识（知识树聚类）可视化为一个可缩放探索的古典海图世界——
**用户的记忆宫殿**：让学习被看见、帮用户理清知识结构、辅助回顾。
活地图行为细节（命名/改名、生长可感知、墨迹浮现、零压力红线）见
`docs/vision/05-记忆宫殿-细节设计.md`。

- 首轮实现（AI 生成贴图路线）已于 2026-07-30 整体废弃移除
- 重启版走**程序化矢量制图**路线（零图片资产），规格见
  `specs/008-procedural-knowledge-map/`，架构决策见 ADR-0004/0005
- 地形引擎集成开源之大成：mapgen4（Apache-2.0）、mewo2/terrain（MIT）、
  Azgaar FMG（MIT）算法移植；Watabou（GPL-3.0）仅取思想净室重写
- 层级映射：知识树深度 0/1/2/3+ → 岛屿/王国/村庄/知识点建筑；
  滚轮缩放即语义缩放；遗忘表现为海图起雾（spec 007）
- 铁律：同一棵树永远生成同一张图；新增知识不移动既有岛屿
