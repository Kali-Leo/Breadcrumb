# 0006. 转 AGPL-3.0，整体采用 Nortantis 资产与 TownGeneratorOS 代码

- **状态**: 已采纳（2026-07-30，Leo 拍板改协议"狠狠使用开源"）
- **上下文**: 自研程序化笔触达不到验收线（Leo："真菌/敷衍三角形"）。视觉北极星定为活点地图：手绘墨线。Nortantis（AGPL-3.0）拥有成套手绘黑线图标与海岸/纸纹算法；TownGeneratorOS（GPL-3.0）是最佳村镇生成器。原 Apache-2.0 无法包含二者。
- **决策**: 仓库协议改为 **AGPL-3.0**（覆盖 GPL/AGPL 依赖的最强 copyleft；本地优先应用无网络条款实际负担）。直接采用 Nortantis 图标资产（符合纯黑线稿合同）并移植其渲染算法；全量移植 TownGeneratorOS 为 `plugin-town`；已移植的 mewo2/Azgaar 算法（MIT）保留。CompassOS/RuneGeneratorOS 无许可证，禁用。第三方清单见 THIRD_PARTY_NOTICES.md。ADR-0004"零图片资产"修订为"允许经 Leo 验收的开源手绘线稿资产"。
- **后果**: 未来社区插件与任何闭源分发路径受 AGPL 传染约束（Leo 知情接受）；换取立即可用的成熟美术与村镇生成。升级第三方版本时按 NOTICES 逐项核对。
