# 0004. 知识地图：程序化矢量制图，零图片资产

- **状态**: 已采纳（2026-07-30，Leo 确认方向后）
- **上下文**: 贴图路线（AI 生图 + 人工验收）已整体废弃：验收成本高、纹理格式脆弱、素材永远不足。参考 Azgaar FMG（MIT）与 Martin O'Leary terrain 笔记（MIT）验证了 Voronoi + 噪声 + 分层渲染可产出高水准古典海图。
- **决策**: 地图完全由代码生成与绘制。无头包 `plugin-map` 负责几何（依赖 `d3-delaunay`、`simplex-noise`，均 MIT、活跃维护、体积小）；渲染沿用 ADR-0003 的 PixiJS v8 + pixi-viewport，全部用 Graphics/Text 画线稿，仓库不再有地图图片资产。确定性：节点 id 哈希 → mulberry32 种子，同树同图。Watabou TownGeneratorOS 为 GPL-3.0，仅作视觉参考，禁止移植其代码。
- **后果**: 美术验收对象从"素材"变为"渲染效果对照板"；风格调整=改代码常量，可回滚可 diff。放弃了手绘贴图的质感上限，换取无限缩放、确定性与零资产维护。
