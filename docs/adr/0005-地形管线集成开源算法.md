# 0005. 记忆宫殿地形管线：集成开源算法（忠实移植，不再简化）

- **状态**: 已采纳（2026-07-30，Leo 明确"加法做到极限、集开源之大成"）
- **上下文**: 首版程序化地形只借思想未移植算法（196 单元/单层噪声），观感远逊参考项目。本仓库 Apache-2.0。
- **决策**: 忠实移植经许可证核验的算法——mapgen4+dual-mesh（Apache-2.0，河网/网格思想）、mewo2/terrain（MIT，fillSinks/flux/erode 侵蚀管线、坡度排线、标签避让）、Azgaar FMG（MIT，hill/range 斑块高度图模板）。新依赖：poisson-disk-sampling、polygon-clipping、polygon-offset、roughjs（均 MIT，蓝噪声采样/真缓冲水波线/手绘颤线）。Watabou 系 GPL-3.0，**代码禁入**，村落层仅按其公开 devlog 思想净室重写（block-centric ward 网格 + Parish&Müller 道路生长）。
- **后果**: 每岛单元数 196→2000+，生成成本上升，以 (nodeId, sizeTier) 记忆化对冲；美术上限对齐参考项目；许可证边界一次讲清，后续引用照此执行。
