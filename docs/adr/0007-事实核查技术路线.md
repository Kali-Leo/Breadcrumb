# 0004. 事实核查：TS 自研声明分解流水线，不引入 Python

- **状态**: 已批准（2026-07-30，Leo 定方向：路线 1 声明分解+证据核查）
- **上下文**: 成熟开源方案（Loki/OpenFactCheck/RefChecker）全为 Python 研究框架；曾考虑 Python sidecar 进技术栈。
- **决策**: 不引入 Python。核查流水线本质是"LLM 调用 + 网络请求"的薄编排，无任何 Python 生态依赖；以无头 TS 包 `plugin-factcheck` 自研，移植 Loki（MIT）的流水线设计与提示词。理由：sidecar 使安装包 +50~150MB 且三平台打包复杂；Loki 直连 LLM/搜索会绕过计价中心与网络总开关（违反产品原则 2/3），改造成本高于重写。
- **后果**: 未来需本地核查模型（MiniCheck 类）时经 Ollama HTTP 接入，仍无需 Python。证据源经 EvidenceProvider 抽象，MVP 用免 key 源（Wikipedia/DuckDuckGo）。
