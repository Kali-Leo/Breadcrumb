# 0001. 技术栈：Tauri 2 + React/TS strict + SQLite + pnpm monorepo

- **状态**: 已批准（Leo 2026-07-28 授权全权委托）
- **上下文**: 本地优先的单机桌面应用，由 AI 全权开发，需要插件生态与最低的 AI 出错率。
- **决策**: Tauri 2 作应用壳（轻量、原生插件/Sidecar 支持）；React + TypeScript strict（AI 训练分布最主流）；SQLite 单文件数据库 + Drizzle ORM（类型契约）；Zod 校验一切外部输入；pnpm workspaces 物理隔离模块；ts-fsrs 提供遗忘算法。不整仓融合现有开源项目，只吸收算法库。
- **后果**: 移动端后置（Tauri 移动端尚在成熟中可后评估）；Rust 侧保持薄壳，复杂度集中在 TS 侧。
