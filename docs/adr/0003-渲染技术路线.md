# 0003. 知识地图渲染：PixiJS，不采用完整游戏引擎

- **状态**: 已批准（Leo 质询后复核，2026-07-30）
- **上下文**: 实现"生动地图"期间接连受挫，质疑技术路线；调研确认挫折源于开发模式摩擦与具体 bug（16 位灰度 PNG 纹理解码、Vite 动态 URL、StrictMode 竞态），非路线错误。
- **决策**: 保持 Tauri+React 应用壳 + PixiJS v8（2026 评测：非游戏交互图形嵌入 React 的推荐选择，450KB/更快）+ pixi-viewport + GSAP。Godot/Unity 与"内嵌活地图的应用"形态相悖。素材一律 8 位 RGBA PNG（png32）。
- **后果**: 立换 Phaser 触发条件：需要物理/音频/复杂粒子或 Pixi 性能墙。开发环回配套：屏上黑匣子（错误+console 镜像）、mapcheck.sh 一键渲染自检。
