# 隐私与花费 / Privacy and cost

这一页写给想确认"它有没有偷偷做什么"的人。每一条都能在代码里查到。

---

## 你的数据在哪里

**一个文件。** `breadcrumb.db`，SQLite，在你的应用配置目录里
（Linux：`~/.config/app.breadcrumb.desktop/`）。对话、知识图、复习状态，全在里面。
文件创建时权限设为 `0600`（只有你自己能读）。

**没有账号，没有云同步，没有服务器。** 这个项目没有后端。

---

## 什么会离开这台电脑

只有五类，全部可以在设置里的**网络总开关**一次关掉：

| 去哪 | 什么内容 | 什么时候 |
|---|---|---|
| **你自己配置的 AI 服务** | 你发的消息、AI 的回复，以及各功能构造的提示词 | 你对话时，以及各后台功能触发时 |
| 维基百科 / 必应 / DuckDuckGo | 事实核查的检索词，和被引用页面的抓取 | 只有你点「求证」时 |
| 模型引用的网址 | 一次 GET，用于核对引用是否真实 | 只有 🧪 对比资料构建时 |
| Hugging Face | 下载本地嵌入模型（一次，约 120MB） | 首次运行；下载后完全离线 |
| `127.0.0.1:21456` | 本机的浏览兴趣程序 | 只有你打开发现页且装了那个程序时 |

**没有别的了。** 仓库里没有任何遥测、埋点、分析、崩溃上报或自动更新的代码 ——
没有 Sentry、没有 PostHog、没有 beacon、没有 WebSocket。

### 网络总开关是真的开关

它不是十八处 `if` 的约定，而是加在 LLM 层唯一那个 fetch 上的结构性阻断
（`lib/llmConfig.ts` 的 `gatedFetch`）。调用点没法忘记检查，因为只有一扇门，而它是锁着的。

> 这一条是修出来的：曾经确实是十八处 `if`，其中三处漏了 —— 专注模式的讲解和标签缩写
> 在开关关闭时照样把你的文字发了出去。

嵌入模型的下载也受它管，但**已经下载好的模型在离线时照常工作** —— 它本来就不需要网络。

## 研究课题平台：什么都没上传

这是最容易让人怀疑的功能，所以说细一点：

- 课题是**随包的本地常量**，不是从网上拉的。
- 每个课题用 Ed25519 对**规范化 JSON**（键排序、无空白）验签，公钥编译在程序里。
- 课题**不能携带代码或 SQL**：它只是一个 Zod 校验的声明式结构，
  能调的统计函数是四个白名单里的，展示区块只有文本/数值/条形三种，没有任何标记语言。
- 结果写进本地一张表。**`packages/plugin-research` 这个包里没有任何 `fetch`。**
  设计文档里规划的上传通道**尚未实现**，一行都没有。
- 你可以整个关掉，也可以逐条删除已有结果。

## 你的 API 密钥

存在同一个 SQLite 文件的 `settings` 表里，明文。它只会出现在两个地方：
发给你配置的那个 baseUrl 的 `Authorization` 头。就这两处。

已经核对过它**不会**泄漏到：日志、控制台、错误消息、`ai_failures` 表、`llm_calls` 表、
崩溃报告、或研究课题的统计里。仓库和 git 历史里也没有任何密钥。

**已知的不足**：明文存储意味着任何以你的身份运行的程序都能读到它。
数据库文件权限已收紧到 `0600`，但这不等于加密。
把它挪进操作系统钥匙串是待办事项，代价是引入一个系统依赖（Linux 上是 dbus/secret-service），
会让"下载就能跑"这件事变难 —— 所以还没做。

## 钱花在哪里

**这个应用不收费，也不经手你的钱。** 你用的是自己在 AI 服务商那里的账号。

### 每个环节独立计价

设置 → **开关与计价**。每一行显示：

1. 功能名和一句话说明
2. **这一次大概花多少** —— 例如「约 ¥0.0023 每轮对话」
3. 今日和累计的**实际**花费
4. 一个开关

### 那个估价是怎么来的

不是拍脑袋。`apps/desktop/src/lib/purposeUsage.measure.ts` 拿**真实的提示词构造函数**
跑一个固定的真实场景（学了约三个月、知识树 80 个节点、一轮学习模式问答），
量出输入和输出的 token 数；再乘以你所用模型的官方价目。

一个测试在每次测试运行时重新测量并比对（容差 2%）——
改了提示词而不更新数字，构建会红。这样账单页上的数字没法慢慢变成谎话。

### 价目本身

`packages/core-llm/src/modelCatalogue.ts`。每一条都带**读自哪个官方定价页**
和**谁在哪天核对的**。这个约束是有来由的：写这张表时先用了聚合网站的数字，
和官方页逐条核对后发现**大部分是错的**。

价目支持一个模型按不同货币销售（DeepSeek 中国站按人民币、国际站按美元 —— 界面上会让你选）、
分时段定价、以及缓存命中价。**结算按调用发生的那一刻**，而不是按"现在多少钱"。

### 实际会花多少

按 DeepSeek v4-flash 空闲时段的价格，一轮学习模式对话加上全部后台整理，
大约是 **¥0.01 上下**。具体数字以你自己那一页为准 —— 它显示的是真实账本。

## 安全上做过什么

2026-08-31 做过一次四路并行审计（密钥处理、原生面与数据层、渲染与出网、依赖与许可证）。
没有发现正在被利用的漏洞，但补上了这些：

- **`piper_synthesize` 曾接受前端指定的可执行文件路径。** 任何注入到界面里的脚本都能借它
  运行任意程序。现在它会校验将要执行的到底是不是 Piper，输出写进应用自己的缓存目录
  而不是可预测的 `/tmp` 名字。
- **`sql:allow-load` 曾让前端指定任意数据库文件。** 插件解析连接串时绝对路径会整个替换目标，
  配合已授予的 `sql:allow-execute`，那一对权限能读写这台机器上任何 SQLite 文件。
  现在由 Rust 打开本应用自己的那一个，权限已移除。
- **CSP 曾是 `null`。** 现在有一份真实策略（开发和生产各一份）。
  Mermaid 显式声明了它原本默默继承的安全级别，KaTeX 加了尺寸上限，
  链接按协议白名单校验而不是指望 React 拦 `javascript:`。
- **外部 URL 抓取曾没有任何限制。** 模型写一个 `http://127.0.0.1` 就能让应用去拨它，
  并把"某个字符串在不在响应里"回报出来 —— 一个可读的本地服务探针。
  现在拒绝回环与私有地址，限制响应体大小，限制等待时间。
- 兴趣程序的查找不再枚举主目录的子目录（曾经，任何解压出 `interest-model/daemon/app.py`
  的压缩包都会被这个应用无提示地运行）。
- 嵌入调用有了批量上限，中毒的互斥锁能恢复而不是让嵌入功能死到重启。

CI 现在跑 `cargo audit` 和仅限生产依赖的 `pnpm audit`。
GTK3 那一族"无人维护"告警按 id 忽略并注明原因 —— Tauri 2 的 Linux 后端就是 GTK3，
没有可迁移的修补版本。
