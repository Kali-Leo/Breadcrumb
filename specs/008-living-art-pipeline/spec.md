## 动画能力评估（诚实版）

**运行时动画是代码工作，是我的主场**——现有 30fps 循环里的炊烟、雾漂移、飞行缓动
就是证据。需要的不是外部 AI，而是更专业的渲染底座：

| 需求（Leo 描述） | 技术方案 |
|-----------------|---------|
| 猫猫沿村路走、会回家 | 岛内路径系统（贝塞尔小路）+ 路径跟随 + 2 帧步行循环 + 镜像翻转 + 状态机（闲逛→回家→进门淡出→炊烟+1） |
| 炊烟、旗帜、海浪、克拉肯摆动 | 粒子/顶点摆动，时间参数化（现有方案延续） |
| 缩放/漫游动效 | **pixi-viewport**：惯性拖拽、缓动缩放、边界回弹（专业手感开箱即得） |
| 元素出场 | 墨水生长（stroke dash-offset / 遮罩 reveal，呼应活点地图） |
| 渲染底座 | **PixiJS v8**（WebGL 精灵图，千元素无压力）+ **GSAP**（缓动库，现已完全免费） |

**动效的"眼睛"**：连拍截图（数秒内抓 4-8 帧逐帧看）验证运动——已具备。
