# Spec 005: 地区展开与地图导航（M3b）

> 设计依据：docs/vision/04。放大某个地区 → 展开内部知识结构；地图不只是风景，
> 也是导航与锚定的入口。

## 需求

1. **地区内部布局**：每个地点的成员知识点在地点圆盘内按相似度排布
   （相关的靠近），确定性布局
2. **语义缩放 LOD**：
   - 远景（scale < 1.5）：房子/村庄/城镇 + 地名（现状）
   - 近景（scale ≥ 1.5）：地区轮廓淡化为墨水圈，内部知识点显形（小标记 + 标签）
3. **点击即飞行**：远景下点击一个地点 → 相机平滑飞行放大到该地区（~0.5s 缓动）
4. **点击即锚定**：近景下点击某个知识点 → 锚定它并跳回对话页，
   输入框上方出现"📍 正在围绕「×」讨论"——从地图直接开始学习
5. **拖拽不算点击**：移动超过阈值(6px)不触发点击行为

## 验收标准

- [ ] 演示数据下：点击"JavaScript 城"→ 飞入 → 看到 12 个知识点在城内按相关性分布
- [ ] 点击城内"闭包"→ 回到对话页且已锚定闭包
- [ ] 缩放阈值切换平滑，无闪烁；拖拽后松手不误触发点击
- [ ] 内部布局确定性（两次打开位置一致）；有单元测试
- [ ] 全部质量门通过
