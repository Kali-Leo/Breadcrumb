# Spec 009: 美术发射台（素材量产系统）

> Leo 的四条修正（2026-07-29）全部吸收为系统设计原则。

## 设计原则（修正后的世界观）

1. **LOD 是两种语言，不是两种尺寸**
   - **L0 远景**＝制图符号语言：村庄=一簇屋顶记号、城镇=带墙图章、港口=锚记……
     整套符号必须像出自同一支笔（风格①）
   - **L1 近景**＝插画语言：Hogsmeade 式建筑插画（风格②）
   - 两层之间靠缩放阈值交叉淡入切换，互不冒充
2. **同级内一致性靠"族谱生成"保证**：一次生成**整版符号族/角色族**（同一张图里 6-9 个），
   再切片入库——同图必同风，这是一致性的物理保证
3. **规模阶梯是不同的构图**：小屋→村落→城镇→都城，每档独立生成（不是缩放），
   对应知识点数量档位
4. **主题系统**：建筑按主题族生成（如：经院/港埠/工坊/山城/庭园……），
   未来与知识领域配对（编程知识长成工坊镇、人文知识长成经院城）——
   每主题一套 L1 阶梯 + 共用 L0 符号
5. **猫村民选角规则**：是"村民"不是"魔法师"——职业猫（面包师/渔夫/农夫/学者/铁匠/店主…），
   体型有胖有瘦，服装是布衣不是法袍，**禁止法杖/魔法元素**；Q版；与主题可配对

## 发射台构成

```
art/
├── batches/     # 批次定义（JSON：风格、条目、提示词）——版本化的"生产订单"
├── out/<batch>/ # 生成产物（gitignore；审毕入库者拷至 apps/desktop/src/assets/map/）
└── registry.json# 资产台账：名称/等级/主题/规模档/状态(draft|approved)/来源批次
scripts/art/
├── generate.py  # 批量生成：读批次→调 Recraft→下载→格式归一(webp/svg→png)
├── slice.py     # 族谱切片：N×M 网格切分 + trim
└── review.sh    # 出对照表（montage）供目检
```

**流程**：批次定义 → generate → (族谱则 slice) → 我目检（对参考、查一致性、剔废片）
→ 后处理（抠底/trim/褐墨化）→ 台账登记 → 入库
**质量门**：每批次对照表连同结论展示给 Leo，重大风格决策由 Leo 拍板
