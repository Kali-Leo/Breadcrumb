# Spec 003: 用户级知识树（M2.5 · 世界观修正）

> 树是用户的属性，对话只是在树上留下足迹。设计依据见 docs/vision/03-地图与罗盘。

## 需求

1. **全局唯一的知识树**：知识节点按 label 全局去重，属于用户而非某次对话
2. **足迹（sightings）**：每次对话"踩过"某节点（新学或重逢）都记录一条足迹
   （哪次对话、哪条消息、何时）——为 M4 罗盘航迹和 M3 遗忘复习埋数据
3. **右栏双视图**：
   - **本次足迹**：当前对话按时间顺序踩过的节点（航迹雏形）
   - **我的知识树**：全局树（层级视图），跨会话持续生长
4. **重逢即足迹**：提取出的知识点若已在树上，不重复建节点，但记录一次足迹
   （"你又遇到了闭包"——M3 里这就是一次复习信号）
5. **老数据无损迁移**：现有对话级节点合并入全局树（同名保留最早者），
   每个旧节点转为一条足迹

## 验收标准

- [ ] 在两个不同对话里都聊到同一概念 → 全局树上只有一个节点，但有两条足迹
- [ ] "本次足迹"只显示当前对话踩过的节点；"我的知识树"显示全部
- [ ] 升级后 Leo 的既有测试数据完整可见（无节点丢失）
- [ ] 迁移系统带版本追踪：每个迁移精确执行一次
- [ ] 全部质量门与既有测试通过；新逻辑（去重/足迹规划、迁移追踪）有单元测试
