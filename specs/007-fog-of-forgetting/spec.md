# Spec 007: 迷雾——遗忘作为地图天气（M4）

> 设计依据：docs/vision/03 + 04。遗忘不是红色警告，而是海图上起了雾；
> 重访即拨云见日。算法：FSRS（ts-fsrs，Anki 同款）。

## 需求

1. **记忆建模**（无头包 plugin-memory）：
   - 每个知识节点 = 一张 FSRS 卡片；首次足迹 = 学会；每次重逢足迹 = 一次 Good 复习
   - `computeRetention(sightings, now)` → 每节点当前记忆保留率 0~1
2. **地图迷雾**：
   - 远景：地点按成员平均保留率蒙上雾（手绘云团，低保留率雾更浓）；
     雾中的地名变淡但**永远可读**（迷雾是氛围不是惩罚）
   - 近景：节点标记按保留率褪色（墨色→浅灰）
3. **重逢拨雾**：在对话中实质重温某知识（已有的 sighting 机制）后，其保留率回升、雾散
4. **零压力红线**：无数字百分比展示、无"你忘了 X"文案；只有雾的浓淡
5. **计价**：纯本地计算，零成本

## 验收标准

- [ ] 把演示数据某节点的足迹时间改老（模拟久未复习）→ 该地区起雾
- [ ] 与该知识重逢一轮对话 → 雾明显变淡
- [ ] 界面任何地方不出现保留率数字或催促文案
- [ ] retention 计算有单元测试（新学=高、久置=衰减、复习=回升）
- [ ] 全部质量门通过
