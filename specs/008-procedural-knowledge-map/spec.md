## 需求

### 1. 世界映射（无头包 plugin-map）

知识树（`knowledge_nodes`，带 parent_id 的全局树）直接充当层级聚类：

| 树深度 | 地图实体 | 规模表达 |
|---|---|---|
| 0（根） | 岛屿 | 面积档位 ∝ 子树节点数 |
| 1 | 王国（岛内疆域） | 领土格数 ∝ 子树节点数 |
| 2 | 村庄 | 村庄层级 1~4 ∝ 子树节点数 |
| ≥3 | 知识点（建筑/地名） | 挂在最近的深度 2 祖先村庄 |

浅树规则：根无子节点 → 只有岛屿与岛名；王国无子节点 → 疆域内只有王国名。
一切实体名取自节点 `label`。

### 2. 地形生成（每座岛）

- 抖动网格撒点 → d3-delaunay Voronoi 单元
- 高度场 = 径向衰减 + 种子 simplex 噪声；高于海平面的单元为陆地
- 海岸线 = 陆/海单元边界追踪 + Chaikin 平滑
- 王国疆域 = 陆地单元按子树权重做确定性种子扩张（flood-fill），
  疆界沿单元边，天然蜿蜒

### 3. 确定性与稳定性（硬性要求）

- 一切随机性来自「节点 id 哈希 → 种子 PRNG」；**同一棵树两次生成结果逐字节相同**
- 群岛布局：按根节点 created_at 排序 + 黄金角序列布点，固定槽距——
  **新增知识永不移动已有岛屿**；新岛在外圈浮现
- 岛屿面积按档位量化：小幅增长不改变海岸线，跨档才重塑

### 4. 渲染（apps/desktop，PixiJS v8，遵守 ADR-0003/0004）

- 羊皮纸底色 + 全程序化墨线：海岸双线 + 岸外排线点划、王国虚线疆界 +
  低饱和淡彩区分、高地 ∧ 山丘符号、村庄小屋符号簇（按层级 1~4 座）、衬线体地名
- 语义缩放三段：地理层（只见岛与岛名）→ 国度层（疆界与国名、村庄圆点）→
  村落层（村庄符号与名、知识点地名）；层间透明度交叉淡入
- pixi-viewport 惯性平移缩放；点击地名飞行定位
- StrictMode 安全：挂载守卫 + 完整销毁，禁模块级可变状态
- 开发环回：DEV 模式键 1~5 缩放预设、键 0 切换演示数据集；
  scripts/dev/mapsweep.sh 一键连拍

### 5. 遗忘迷雾（完成 spec 007 T3）

- 地点保留率 = 子树成员平均 retention（memoryStore，纯本地）
- 低保留率处覆软白雾团；地名透明度设下限，**永远可读**
- 零压力红线：无百分比、无催促文案，只有雾的浓淡

### 6. 空态与减压语言

- 无知识时：安静的空海 + 「海图待展开——去聊聊天，第一座岛屿会浮现」
- 全程只用"已完成/已探索"语言，不出现任何进度压力表达
