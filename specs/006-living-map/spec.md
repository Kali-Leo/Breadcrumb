# Spec 006: 生机层（M3c）

> 设计依据：docs/vision/04 —— "学习的奖赏是我的世界热闹起来了"。
> 纯视觉生命力，不承载任何学习功能，也绝不施压。

## 需求

1. **动画心跳**：地图页运行 ~30fps 的绘制循环（仅地图页挂载时运行，离开即停，省电）
2. **炊烟**：远景下，房子与村庄的烟囱偶尔升起 2-3 缕手绘烟圈（几秒一次的呼吸节奏，
   各地点相位错开，确定性）
3. **居民猫猫**：城镇有 2 只、村庄有 1 只墨水小猫在地点边缘散步（来回踱步 + 尾巴摆动，
   确定性路径）
4. **海面细节**：空白海面撒确定性的短波浪线（低透明度，不喧宾夺主）
5. **罗盘玫瑰**：右上角一枚手绘罗盘装饰（为 M5 罗盘功能预留视觉位置）
6. **性能**：演示数据规模下 CPU 占用无感；切出地图页后零绘制开销

## 任务

- [x] T1 mapRender：装饰层（炊烟/猫猫/波浪/罗盘玫瑰），时间参数化、逐地点相位错开
- [x] T2 MapView：rAF 绘制循环重构（替代逐 render 重画），卸载即停
- [ ] T3 手感微调 + 质量门 + 文档
