# Spec 004: 知识地图雏形（M3a）

> 设计依据：docs/vision/04-知识地图-墨水航海图。本期只做"能漫游的活地图"，
> 地区展开(M3b)、猫猫(M3c)、迷雾(M4)后续。

## 需求

1. **本地词向量**：Rust 侧集成 fastembed（多语言小模型），Tauri command `embed_texts`；
   模型首次联网下载后永久离线；离线且无缓存时嵌入任务安静排队，不影响任何功能
2. **嵌入管线**：新知识节点落库后自动计算并存储 embedding（node_embeddings 表）；
   启动时补算存量节点
3. **地图布局**（无头包 plugin-map）：余弦相似度 → kNN 相似图 → 力导向布局
   （相关=近，无关=远）→ 阈值聚类成"地区"；布局确定性（同样输入同样地图）
4. **地图页**（新视图 🗺️）：
   - 墨水航海图观感 v1：纸色背景 + rough.js 手绘轮廓 + 地名标注
   - 地点规模随节点数生长：小房子(1-2) → 村庄(3-7) → 城镇(8+)
   - 滚轮缩放 + 拖拽漫游；在空白处放大有回弹；全局视图 ↔ 地区视图两级 LOD
5. **计价原则**：本地嵌入不花钱不计价，但模型下载遵守网络总开关

## 验收标准

- [ ] 聊过 ≥2 个不相关主题后打开地图：出现 ≥2 个隔海相望的地点，相关知识聚在一起
- [ ] 继续学习某主题 → 该地点变大（房子→村庄）
- [ ] 断网时应用一切正常，嵌入排队；联网后自动补算
- [ ] 缩放漫游手感顺滑，空白处放大回弹
- [ ] 布局逻辑（相似图/聚类/规模分级）有单元测试；全部质量门通过
